# Contributing to Awesome AI Video

Thanks for helping keep this list useful and accurate. Quality over quantity.

## Guidelines

- **One entry per pull request** (or a small, related batch) so it's easy to review.
- **Link to the official source** — the project's own site, GitHub repo, or docs.
  No affiliate links, no SEO-farm reposts.
- **Add one concise sentence** describing what makes the entry worth knowing —
  what it does well, not marketing copy.
- **Tag it** with the right marker: 🔓 open-source / 💲 commercial / 🆓 free tier.
- **Keep the right section** and alphabetical-ish / quality order within it.
- **Make sure it works** — no dead links, and the project should be real and usable
  (not vaporware or an unreleased waitlist).

## Format

```markdown
- [Name](https://official-url) 🔓 — One sentence on why it's worth knowing.
```

## Removing entries

If a project is discontinued, abandoned, or its link is dead, a PR that removes or
updates it is just as welcome as one that adds something.

## Submitting

1. Fork the repo and create a branch.
2. Edit `README.md`.
3. Open a pull request describing what you added/changed and why.

By contributing, you agree to release your contributions under the
[CC0 1.0 Universal](LICENSE) dedication.
